# Knot
ふたりを結ぶすべてをひとつに。
Knotは、恋人同士の2人が関係に関する情報、思い出、予定、気持ちを一元管理するためのプライベートプラットフォームアプリです。

## Features

- ユーザー登録・ログイン
- カップル作成・招待
- ホーム画面
- カレンダー
- メモ
- 思い出投稿・画像管理

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- PWA

### Backend
- Node.js
- TypeScript
- Express
- Prisma

### Database
- MySQL

### Infrastructure
- Sakura VPS
- nginx
- Docker

## Project Structure
- frontend/ : フロントエンド
- backend/ : バックエンド
- nginx/ : nginx設定
- docker/ : Docker関連設定
- docs/ : 設計書
- scripts/ : 運用・初期化スクリプト
